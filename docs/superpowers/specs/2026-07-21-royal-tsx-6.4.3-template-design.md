# Royal TSX 6.4.3 Template Support Design

## Goal

Add a localization template for Royal TSX 6.4.3 (build 6.4.3.1000) while preserving support for 6.3.0.1000. Make 6.4.3.1000 the default template and verify template integrity before modifying an app bundle.

## Template Layout

Create `templates/6.4.3.1000/` with the same four target paths used by the existing workflow:

- `Contents/Resources/zh-Hans.lproj/Localizable.strings`
- `Contents/Frameworks/RoyalTSXNativeUI.framework/Versions/A/Resources/PluginGallery/index.html`
- `Contents/Frameworks/RoyalTSXNativeUI.framework/Versions/A/Resources/PluginGallery/js/language.js`
- `Contents/Frameworks/RoyalTSXNativeUI.framework/Versions/A/Resources/PluginGallery/js/language_zh.js`

The main localization retains the existing 1,938 Chinese translations because the 6.4.3 English localization has the same complete key set as 6.3. The Plugin Gallery files are based on the installed 6.4.3 resources, with the Chinese script include and normalized language-code handling applied. The existing Chinese Plugin Gallery dictionary is retained because the upstream English dictionary is unchanged.

## Script Behavior

Change the default template version to `6.4.3.1000`. Keep `--version` so users can explicitly select `6.3.0.1000`.

Before backup or replacement, read the selected template's `MANIFEST.txt`, validate its format, and verify SHA-256 for every target file. A missing entry, unexpected target, duplicate entry, or checksum mismatch stops execution before the app bundle is changed.

Existing app discovery, backup, dry-run, and version mismatch reporting remain unchanged.

## Documentation

Update the README to list both supported builds, identify 6.4.3.1000 as the default, and document automatic manifest verification.

## Verification

- Parse both `.strings` files with `plutil` and confirm the 6.4.3 localization contains exactly the installed English key set.
- Check JavaScript syntax for `language.js` and `language_zh.js` with Node.js.
- Recalculate and validate both template manifests.
- Run `--dry-run` against the installed Royal TSX 6.4.3 app.
- Copy the minimum app fixture to a temporary directory, run an actual replacement, and confirm all four files match the 6.4.3 template and backups are created.
- Confirm the repository worktree contains only the intended source, template, documentation, and test-related changes before pushing `main`.
